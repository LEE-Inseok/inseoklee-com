## Content

Anthropic's training on writing prompts that hold up in production environments:

- Task decomposition and prompt structure
- Examples, format constraints, and chain-of-thought patterns
- Evaluation harnesses and prompt regression testing
- Iteration loops between prompt drafts and downstream metrics
- Versioning prompts as part of the engineering artifact

## Application

The prompting patterns from this course inform every Codex cross-validation request, every research-toolkit invocation, and the prompt templates used by specialist subagents in the agent orchestration setup.
